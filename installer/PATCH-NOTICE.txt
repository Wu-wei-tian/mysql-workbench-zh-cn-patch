MySQL Workbench 26.7.0 简体中文补丁 — 预览版 1

适用于已经安装原版 Windows x64 Workbench 26.7.0 的电脑。
本补丁完全离线，不重复安装 Workbench 运行环境。

请选择现有安装目录。安装前会逐一校验待修改资源的 SHA-256。
不兼容的版本或未知修改会被拒绝。原始资源会先备份并校验，然后再安装补丁。

补丁保留现有个人配置、连接及 SQL 脚本，不读取保存的凭据，
不修改 MySQL Server 或数据库。安装或卸载补丁前，请关闭 Workbench。

恢复英文时，仅卸载名为“简体中文补丁 / Simplified Chinese Patch”的条目。
请勿误卸载原版 Workbench。经校验的原始文件会保留在 localization\original 中。
如果原版升级或资源被其他程序修改，恢复程序会停止，避免旧文件覆盖新文件。

这是非官方社区汉化预览版，不是 Oracle 官方发行版。
部分动态后端消息、编辑器命令及外部帮助仍为英文。
尚未在干净 Windows 虚拟机中完成兼容性验证，详见测试报告。
