MySQL Workbench 26.7.0 简体中文社区汉化版

这是独立制作的非官方汉化预览版（zh.1），不是 Oracle 官方中文版。

已经安装 Workbench：优先使用汉化补丁

运行 MySQL-Workbench-26.7.0-zh-CN-Patch.exe。补丁完全离线，不重复下载 Workbench。
关闭 Workbench 后，选择现有的 26.7.0 x64 安装目录；通常为
C:\Program Files\MySQL\MySQL Workbench。安装到 Program Files 时需要管理员授权。

补丁支持本项目核验过的 26.7.0 MSI 和 ZIP 两种资源布局。安装前逐一校验需要修改的文件；
不兼容版本或已被其他补丁修改的资源会被拒绝，不会强行覆盖。
原文件保存在安装目录的 localization\original 下。补丁沿用原版个人配置，不读取保存的密码。

恢复英文：在 Windows“已安装的应用”中仅卸载“简体中文补丁 / Simplified Chinese Patch”条目。
它会校验备份并恢复原文件。不要误卸载原版 Workbench。
若原程序升级后资源哈希已改变，恢复程序会停止，以免旧文件覆盖新版文件。
备份目录会保留，供人工恢复使用；请勿把旧备份覆盖到其他版本。

没有安装 Workbench：使用独立安装程序

运行 MySQL-Workbench-26.7.0-zh-CN-Setup.exe，选择新目录。
程序会从 MySQL 官方下载约 318 MiB 的 26.7.0 x64 ZIP 包，校验 SHA-256 后安装并汉化。
无需预装 Workbench、Node.js、Python 或构建工具。需要可用的网络连接和约 2 GB 临时空间。
这是联网完整安装流程，不是单文件离线完整安装包。

如果您已自行从官方下载 mysql-workbench-26.7.0-winx64.zip，可放在安装程序旁边，
安装时会校验后使用，避免重复下载。不要将未经许可审查的完整运行时重新分发。

独立版默认安装到当前用户目录，无需管理员权限；可选择提升权限。
与原版并存，不覆盖原版，不自动迁移连接。其个人数据位于
%APPDATA%\MySQL Workbench zh-CN。卸载保留个人数据及用户自行添加的文件。

使用

默认简体中文。通过“语言 / Language”菜单选择 English 或简体中文，保存工作并重启后生效。
独立版也提供 English 开始菜单快捷方式。重装不会删除连接、SQL 文件或数据库。
本项目不安装 MySQL Server，不修改其服务、配置或数据目录。

已知限制

- 当前为预览版，不能宣称“全部汉化”或“已完成全部兼容性认证”。
- 部分动态后端错误、密码提示、编辑器内置命令、系统变量说明、运行状态和外部帮助仍为英文。
- SQL、对象名称、用户数据、配置键、协议字段、产品名称和必要技术术语保留原样。
- 原版 26.7.0 的结果集导入/导出菜单在源码中处于禁用状态；本补丁不将未实现功能伪装成可用功能。
- 本安装程序未使用商业代码签名证书签名。官方 EXE/DLL 保持原样；资源修改不代表 Oracle 对汉化版背书。
- 本机 MSI 版主程序的 Oracle 签名保持有效；官方 ZIP 版主程序原本就未签名，独立安装版保留其原始状态。
- Windows 10、干净虚拟机和另一台实体电脑上的验证状态见 TEST_REPORT.txt。
- 自动更新后可能需要重新制作匹配资源哈希的补丁，不支持盲目跨版本覆盖。

维护源码和翻译资源见 localization-source.zip，官方对应 Workbench 源码随安装程序提供。
构建步骤、许可范围及测试证据见 BUILD.txt、SOURCE-LICENSE-NOTICE.txt、TEST_REPORT.txt。
