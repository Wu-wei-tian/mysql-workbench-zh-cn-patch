Evidence and reproducibility

See the accompanying validation directory for selected build/install logs, JSON results, version/signature analysis and screenshots. Raw development logs remain in the workspace logs directory. Earlier development runs encountered asynchronous password-dialog timing and hidden-window screenshot timeouts; the test harness was corrected and the final listed runs passed. Earlier failed runs are not counted as passing tests.

The source archive includes tests/localization.test.cjs, tests/e2e.cjs, tests/installer-lifecycle.ps1, tests/standalone-lifecycle.ps1, tests/start-test-db.ps1 and tests/data-roundtrip.py. Follow BUILD.txt; never redirect these tests to a personal or production database.

The final packaging pass may change installer hashes because it embeds this report and updated source documentation. Test results apply to the listed runtime, installer logic and payload fingerprints; SHA256SUMS.txt identifies the delivered artifacts.

Inno Setup compilation succeeds with non-fatal warnings for three obsolete keys retained in the upstream community language file and the supported FileCopy compatibility alias. Missing new Chinese wizard messages are supplied by this project's separate override file.
